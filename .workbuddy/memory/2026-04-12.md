## 登录回弹 + 远程数据不显示 修复

### 根因分析
1. **MySQL LIMIT/OFFSET 参数化问题**: `mysql2` 的 `execute()` 会把占位符参数作为字符串传递，导致 `LIMIT ? OFFSET ?` 报错 `Incorrect arguments to mysqld_stmt_execute`
2. **错误级联**: MySQL 查询失败 → `isConnected` 设为 false → 所有后续请求跳过 MySQL 走 JSON 降级 → JSON DB 无数据 → 页面空白
3. **repository.js 方法缺失**: `searchQuestions`、`randomQuestions`、`getQuestionsByIds`、`getExamRecordCountByIp` 方法在之前的优化中被引用但未添加到 repository.js
4. **withFallback 日志 bug**: `[{label}]` 未用模板字符串 `${label}`，导致日志显示字面量

### 修复内容
- **repository.js**: 添加 `searchQuestions()`（分页+过滤+LIKE转义）、`randomQuestions()`（随机组卷）、`getQuestionsByIds()`（批量查询）、`getExamRecordCountByIp()`（IP计数）
- **repository.js**: 修复 `parseJSONField()` 未定义的问题，添加本地定义
- **repository.js**: LIMIT/OFFSET 改为字符串拼接（`parseInt()` 确保安全），不用参数化占位符
- **repository.js**: 修复 `withFallback` 中两处 `[{label}]` → `[${label}]`
- **auth.js（路由）**: 登录/注册时先 `clearCookie('token')` 再 `setCookie`，防止旧 secret 签发的 token 残留
- **auth.js（路由）**: 登录/注册响应中同时返回 token（用于 Authorization header，双重保障）
- **auth.js（中间件）**: 添加调试日志（token来源、验证失败详情）
- **前端 Login.vue**: 登录后保存 token 到 localStorage，先验证 Cookie/header 可用再跳转
- **前端 api/index.js**: axios 请求拦截器自动添加 `Authorization: Bearer <token>` header
- **前端 api/index.js**: 401 拦截器改用 `setTimeout + window.location.href` 替代动态 import router
- **前端 router/index.js**: 路由守卫同时发送 Cookie 和 Authorization header
- **前端 stores/user.js**: login 保存 token，logout 清除 token
- **前端 Profile.vue**: logout 清除 localStorage token
- **QuestionsPanel.vue**: 修复嵌套模板字符串语法错误（反引号冲突）

### 认证策略变更
- 从纯 HttpOnly Cookie → Cookie + Authorization header 双重保障
- 登录响应返回 token 供前端存储（localStorage）
- axios 拦截器自动添加 Authorization header
- 即使 Cookie 失效（旧 secret、跨域等），Authorization header 仍能认证
