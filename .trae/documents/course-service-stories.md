## Epic 1: 创建与管理课程

### US-01: 作为讲师，我想新建一门课程
**优先级**: P0 | **阶段**: Phase 1

**验收标准 (AC)**:
- [ ] 可以在 Dashboard "课程" Tab 中点击"新建课程"按钮
- [ ] 弹出对话框/页面，可填写：标题(必填)、描述、选择可见性、上传封面图
- [ ] 标题不能为空，长度限制 1-200 字符
- [ ] 描述可选，支持富文本或纯文本
- [ ] 封面图可选，通过已有上传接口上传
- [ ] 默认可见性为 `public`
- [ ] 创建成功后自动进入课程编辑器
- [ ] 创建失败时显示具体错误原因

**前置条件**: 用户已登录且角色为 trainer 或 admin

---

### US-02: 作为讲师，我想编辑课程基本信息
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 可以修改标题、描述、封面图、可见性设置
- [ ] 修改后立即生效（草稿状态无需重新发布）
- [ ] 已发布课程的修改需要确认提示

---

### US-03: 作为讲师/管理员，我想删除课程
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 删除前弹出二次确认框（"删除后不可恢复，确定删除？"）
- [ ] 只有创建者或 admin 可以删除
- [ ] 删除时同时删除所有关联的章节数据和授权记录
- [ ] 已发布的课程删除需额外警告

---

### US-04: 作为用户，我想查看我的课程列表
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 课程列表以卡片形式展示
- [ ] 每张卡片显示：封面缩略图、标题、状态标签(draft/published)、章节数、浏览量、更新时间
- [ ] 支持按标题搜索
- [ ] 支持按状态筛选（全部/草稿/已发布）
- [ ] Admin 可查看所有人的课程，普通用户只看自己的
- [ ] 支持分页，默认每页 12 条
- [ ] 空状态显示引导文案"还没有课程，立即创建第一门课吧"

---

## Epic 2: 管理课程内容（章节与富文本）

### US-05: 作为讲师，我想添加/编辑章节内容
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 在课程编辑器中左侧展示章节树形列表
- [ ] 可添加顶级章节（输入标题后回车或点击按钮）
- [ ] 可添加子章节（选中父节点后添加）
- [ ] 支持 3 级嵌套（顶级 → 子章节 → 小节）
- [ ] 每个章节点击后在右侧打开富文本编辑器
- [ ] 富文本编辑器功能：标题/正文/代码块/表格/图片/列表/引用
- [ ] 图片通过已有 upload API 上传
- [ ] 自动保存（防丢）或手动保存
- [ ] 章节标题必填，内容可为空（占位用）

---

### US-06: 作为讲师，我想拖拽排序章节
**优先级**: P1 | **阶段**: Phase 1

**AC**:
- [ ] 章节支持上下拖拽调整顺序
- [ ] 同级章节间可拖拽
- [ ] 可跨父节点拖拽（改变层级关系）
- [ ] 拖拽后实时保存新排序
- [ ] 拖拽过程有视觉反馈（占位线/高亮）

---

### US-07: 作为讲师，我想将章节设为草稿/发布
**优先级**: P1 | **阶段**: Phase 1

**AC**:
- [ ] 每个章节有独立的状态开关（draft / published）
- [ ] 草稿状态的章节在公开访问页不可见
- [ ] 支持批量操作：全选 → 批量发布 / 批量设为草稿
- [ ] 发布的章节旁边有绿色标记，草稿为灰色

---

### US-08: 作为讲师，我想删除章节
**优先级**: P1 | **阶段**: Phase 1

**AC**:
- [ ] 删除单个章节（带确认提示）
- [ ] 删除父章节时提示是否同时删除子章节
- [ ] 至少保留一个顶级章节（不允许全部删空）

---

## Epic 3: 发布与权限控制

### US-09: 作为讲师，我想发布/下架课程
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 草稿课程可以一键"发布"
- [ ] 已发布课程可以"下架"（回到草稿）
- [ ] 下架后公开访问页显示"该课程暂未发布"
- [ ] 发布操作记录审计日志
- [ ] 发布前检查：至少有一个已发布的章节

---

### US-10: 作为讲师，我想获取课程分享链接
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 每门课程有唯一的公开访问 URL（如 `/course/42` 或 `/course/python-basic`）
- [ ] 点击"复制链接"按钮复制到剪贴板
- [ ] 链接格式友好（可选 slug 如 `/course/python-basic`）
- [ ] 未发布的课程也可复制链接（但访问时会看到"未发布"提示）

---

### US-11: 作为讲师，我想设置课程为密码保护模式
**优先级**: P1 | **阶段**: Phase 2

**AC**:
- [ ] 可见性选项中选择 `password` 模式
- [ ] 设置 4-20 位访问密码
- [ ] 访问者首次打开时需输入正确密码
- [ ] 密码验证通过后在当前会话保持解锁状态（sessionStorage）
- [ ] 可以随时修改或清除密码
- [ ] 密码错误时显示提示（不区分"不存在"和"密码错误"）

---

### US-12: 作为讲师，我想将课程设为私有并指定允许的用户
**优先级**: P1 | **阶段**: Phase 2

**AC**:
- [ ] 可见性选项中选择 `private` 模式
- [ ] 可以搜索并添加系统中的用户到允许列表
- [ ] 可以从允许列表中移除用户
- [ ] 不在列表中的用户（包括登录用户）访问时显示"无权访问"
- [ ] Admin 用户不受私有限制（始终可访问）

---

### US-13: 作为访客，我想无需登录即可查看公开课程
**优先级**: P0 | **阶段**: Phase 1

**AC**:
- [ ] 通过链接直接访问 `/course/:id`
- [ ] 无需登录即可查看课程内容和章节目录
- [ ] 页面包含：课程封面、标题、描述、章节目录、主内容区
- [ ] 点击目录项切换章节内容（无刷新）
- [ ] 支持上一篇/下一篇导航
- [ ] 页面底部显示版权信息和版本号
- [ ] 404 时显示友好的"课程不存在"页面

---

### US-14: 作为访客，我想通过密码访问受保护的课程
**优先级**: P1 | **阶段**: Phase 2

**AC**:
- [ ] 访问 password 模式的课程时显示密码输入界面
- [ ] 输入正确密码后跳转到课程首页
- [ ] 密码错误时抖动动画 + 错误提示
- [ ] 解锁状态在当前浏览器会话保持（关闭标签页后失效）
- [ ] 密码输入框支持回车提交

---

### US-15: 作为登录用户，我想访问私有课程
**优先级**: P1 | **阶段**: Phase 2

**AC**:
- [ ] 访问 private 课程时如果未登录，跳转登录页
- [ ] 登录后自动返回课程页
- [ ] 如果当前登录用户不在允许列表中，显示"您没有访问权限"
- [ ] 如果在允许列表中，正常显示课程内容
- [ ] Admin 角色可访问所有私有课程

---

### US-16: 作为学习者，我想通过目录快速定位章节
**优先级**: P2 | **阶段: Phase 3**

**AC**:
- [ ] 左侧目录树高亮当前正在阅读的章节
- [ ] 支持折叠/展开父章节
- [ ] 长目录支持滚动
- [ ] 移动端目录可收起为汉堡菜单
- [ ] 章节数量较多时显示进度百分比

---

## Epic 4: 数据统计

### US-17: 作为讲师，我想查看课程的浏览量统计
**优先级**: P1 | **阶段**: Phase 2

**AC**:
- [ ] 课程列表卡片上显示浏览量数字
- [ ] 课程详情页（管理端）显示总浏览量趋势
- [ ] 每个章节独立统计阅读量
- [ ] 浏览量去重（同一用户多次访问算一次，基于 IP + cookie）

---

### US-18: 作为讲师，我想了解哪些章节最受欢迎
**优先级**: P2 | **阶段**: Phase 3

**AC**:
- [ ] 课程详情页展示"热门章节 TOP 5"排行
- [ ] 显示每个热门章节的阅读量占比
- [ ] 可按阅读量排序章节列表

## 技术故事（非面向用户的内部需求）

### TEC-01: 数据库表自动初始化
**AC**:
- [ ] courses/chapters/course_access 三张表在服务启动时自动创建
- [ ] ensureColumns() 包含所有字段定义
- [ ] ensureIndexes() 包含必要索引
- [ ] 缺失列自动 ALTER TABLE ADD

### TEC-02: API 输入验证
**AC**:
- [ ] 所有 POST/PUT 路由使用 Joi schema 验证
- [ ] course title: 必填, 1-200字符
- [ ] chapter title: 必填, 1-200字符
- [ ] visibility: 枚举值校验 (public/password/private/link)
- [ ] content: 最大 5MB (防 DoS)
- [ ] page/pageSize: 数字范围校验

### TEC-03: 权限中间件复用
**AC**:
- [ ] 课程 CRUD 使用 requireAdminOrOwner(getCourseOwnerId)
- [ ] 章节管理继承课程的权限
- [ ] 公开访问路由不走 authenticate
- [ ] 私有课程访问走可选认证 + 校验逻辑

### TEC-04: 前端组件规范
**AC**:
- [ ] CoursesPanel.vue 遵循 Dashboard activatedTabs 懒加载模式
- [ ] CourseView.vue 为独立路由页面（无需认证）
- [ ] 富文本编辑复用 wangEditor 配置
- [ ] 内容渲染使用 SafeHtml 组件
- [ ] 所有 API 调用统一走 api/index.js
