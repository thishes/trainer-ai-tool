## 二、用户故事板

### 场景 1：培训师创建考试流程

#### 用户画像
**姓名**：张老师  
**角色**：培训师  
**目标**：创建一场新的考试并安排学员参加

#### 当前体验（痛点分析）

```
登录 → 进入 Dashboard → 创建试卷 → 选择题目 → 保存 → 安排考试 → 通知学员
```

**痛点**：
- ❌ 创建试卷流程繁琐，需要多次跳转
- ❌ 选题目时无法预览完整题目
- ❌ 无法批量操作
- ❌ 没有草稿箱功能
- ❌ 安排考试后无法一键通知学员

#### 理想体验

```
登录 → Dashboard 显示"创建考试"快捷入口 → 
弹出向导（3 步）：
  1. 填写考试基本信息
  2. 智能选题（可手动调整）
  3. 确认并发布
→ 自动通知学员 → 完成
```

**优化点**：
- ✅ 考试创建向导（分步引导）
- ✅ 题目预览功能
- ✅ 批量选题
- ✅ 草稿自动保存
- ✅ 一键通知学员

## 五、技术实现要点

### 1. 考试创建向导
**技术栈**：
- Arco Design Steps 组件
- 拖拽排序（vuedraggable）
- 本地存储（草稿保存）

**关键代码**：
```javascript
// 向导状态管理
const wizardSteps = [
  { title: '基本信息', key: 'basic' },
  { title: '选择题目', key: 'questions' },
  { title: '确认发布', key: 'confirm' }
]

// 草稿自动保存
watch(paperForm, (newVal) => {
  localStorage.setItem('paper_draft', JSON.stringify(newVal))
}, { deep: true, debounce: 1000 })
```

### 2. 答题界面优化
**技术栈**：
- WebSocket（实时保存）
- 本地存储（防丢失）
- 倒计时组件

**关键代码**：
```javascript
// 答案自动保存
const saveAnswer = debounce(async (questionId, answer) => {
  await api.saveAnswer({ questionId, answer })
  Message.success('答案已保存')
}, 2000)

// 倒计时提醒
const countdown = ref(examDuration)
watch(countdown, (val) => {
  if (val <= 300) { // 剩余 5 分钟
    Message.warning('考试即将结束，请检查答案')
  }
})
```

### 3. 批量导入
**技术栈**：
- xlsx（Excel 解析）
- 批量 API 调用
- 进度条显示

**关键代码**：
```javascript
// Excel 解析
import { read, utils } from 'xlsx'

const handleImport = async (file) => {
  const data = read(file, { type: 'array' })
  const rows = utils.sheet_to_json(data.Sheets[data.SheetNames[0]])
  
  // 批量导入
  const result = await api.batchImport(rows)
  Message.success(`成功导入${result.success}条，失败${result.failed}条`)
}
```
