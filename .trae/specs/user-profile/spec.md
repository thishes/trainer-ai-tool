# 用户中心增强规格文档

## Why
当前侧边栏头像功能简单，需要升级为完整的用户中心，提供基本信息修改和安全设置功能。

## What Changes

### 1. 头像组件升级
- 将当前简单头像替换为 Arco Design Avatar 组件
- 支持图片、图标或字符形式展示
- 点击头像可进入用户中心

### 2. 用户中心页面
新增用户中心页面，包含以下功能：

#### 2.1 基本信息
- 头像上传/修改
- 用户名显示（不可修改）
- 角色显示
- 手机号修改
- 邮箱修改（可选）

#### 2.2 安全中心
- 修改密码
- 密码强度提示
- 确认新密码
- 验证当前密码

### 3. 前端路由
- 新增 `/profile` 路由
- 用户中心入口：侧边栏头像点击

## Impact
- 需要修改: Dashboard.vue (头像), 新增 Profile.vue
- 需要后端: 用户信息更新API, 密码修改API
