## 用户旅程地图

### 场景 1：首次登录完善信息

#### 当前体验
```
登录 → 进入用户中心 → 看到空白头像 → 不知道能不能修改 → 只看到手机号可填
```

**问题**：
- ❌ 没有引导提示
- ❌ 头像不可修改，感觉不完整
- ❌ 不知道哪些是必填项
- ❌ 没有保存草稿功能

#### 理想体验
```
登录 → 欢迎弹窗提示完善信息 → 引导式表单（头像 → 昵称 → 手机号） → 实时保存 → 完成提示
```

**优化点**：
- ✅ 新用户引导弹窗
- ✅ 进度指示（3 步完成）
- ✅ 头像上传预览
- ✅ 自动保存草稿
- ✅ 完成奖励提示

---

### 场景 2：修改手机号

#### 当前体验
```
用户中心 → 修改手机号 → 输入新号码 → 保存 → 成功
```

**问题**：
- ❌ 没有确认步骤，担心误操作
- ❌ 没有历史手机号记录
- ❌ 没有短信验证码（安全风险）

#### 理想体验
```
用户中心 → 点击手机号编辑 → 输入新号码 → 获取验证码 → 验证通过 → 确认修改 → 成功提示 → 发送通知
```

**优化点**：
- ✅ 短信验证码验证
- ✅ 修改确认对话框
- ✅ 历史手机号记录（最近 3 次）
- ✅ 修改成功通知（站内信/微信）

---

### 场景 3：修改密码

#### 当前体验
```
安全中心 → 输入当前密码 → 输入新密码 → 确认新密码 → 修改 → 强制登出
```

**问题**：
- ❌ 密码强度检测不够直观
- ❌ 没有确认步骤
- ❌ 强制登出没有提前告知
- ❌ 没有密码历史记录

#### 理想体验
```
安全中心 → 输入当前密码 → 输入新密码 → 实时强度检测 → 确认新密码 → 确认修改 → 提示将登出 → 成功 → 自动跳转登录页
```

**优化点**：
- ✅ 密码强度实时可视化（进度条 + 颜色）
- ✅ 修改前确认对话框
- ✅ 明确提示"修改后将需要重新登录"
- ✅ 密码历史记录（防止重复使用）
- ✅ 密码过期提醒（可选）

---

### 场景 4：上传头像

#### 当前体验
```
用户中心 → 看到默认头像 → 无法修改 → ❌ 功能缺失
```

**问题**：
- ❌ 功能完全缺失
- ❌ 用户无法个性化

#### 理想体验
```
用户中心 → 点击头像 → 弹出上传框 → 选择图片 → 裁剪调整 → 预览 → 确认 → 成功
```

**优化点**：
- ✅ 支持 JPG/PNG/GIF 格式
- ✅ 自动裁剪为圆形
- ✅ 实时预览
- ✅ 自动压缩为 WebP
- ✅ 上传进度显示

---

### 场景 5：查看个人信息

#### 当前体验
```
用户中心 → 基本信息 → 显示用户名、角色、手机号
```

**问题**：
- ❌ 信息太少
- ❌ 没有账号创建时间
- ❌ 没有最后登录时间
- ❌ 没有账号状态显示

#### 理想体验
```
用户中心 → 基本信息卡片
  - 头像 + 用户名 + 角色徽章
  - 账号信息：创建时间、最后登录、登录次数
  - 联系信息：手机号、邮箱（如有）
  - 个人信息：昵称、性别、生日、简介
```

**优化点**：
- ✅ 账号统计信息
- ✅ 扩展个人信息字段
- ✅ 角色徽章可视化
- ✅ 账号状态标签（正常/锁定）

---

### 场景 6：安全中心管理

#### 当前体验
```
安全中心 → 修改密码 → 完成
```

**问题**：
- ❌ 只有修改密码功能
- ❌ 没有安全状态概览
- ❌ 没有登录记录
- ❌ 没有设备管理

#### 理想体验
```
安全中心 → 安全概览
  - 安全等级评分（基于密码强度、绑定情况）
  - 密码管理：修改密码、密码强度、最后修改时间
  - 账号绑定：微信、邮箱（带状态）
  - 登录记录：最近 10 次登录（时间、地点、设备）
  - 设备管理：已登录设备列表、可远程登出
```

**优化点**：
- ✅ 安全等级评分
- ✅ 密码强度可视化
- ✅ 第三方绑定状态
- ✅ 登录记录查询
- ✅ 设备管理（可选）
