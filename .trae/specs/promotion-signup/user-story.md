# 海报与报名功能增强 - 用户故事板

## 功能概述
为海报与报名模块增加完整的报名管理功能，包括预览、报名、名单管理等功能。

---

## 用户角色
1. **创建者（管理员/培训师）** - 创建文案、管理报名、查看名单
2. **报名者（学员）** - 查看文案、提交报名信息

---

## 用户故事

### 故事1：创建者预览文案
**作为** 创建者  
**我希望** 在发布前预览文案效果  
**以便** 确认网页版和手机版的展示效果

#### 验收标准
- [ ] 点击"预览"按钮打开全屏预览弹窗
- [ ] 左侧显示网页版样式（宽度~800px）
- [ ] 右侧显示手机版样式（宽度~375px）
- [ ] 两个版本上方都显示二维码（可扫描）
- [ ] 两个版本上方都显示可复制的外链网址
- [ ] 点击遮罩层或关闭按钮可关闭预览

---

### 故事2：创建者开启报名功能
**作为** 创建者  
**我希望** 在编辑文案时开启报名功能  
**以便** 收集学员报名信息

#### 验收标准
- [ ] 编辑弹窗中增加"开启报名"开关
- [ ] 开启后显示报名配置区域
- [ ] 可添加/编辑/删除班级班次（如："第一期-北京班"、"第二期-上海班"）
- [ ] 每个班次包含：班次名称、名额限制（可选）、报名截止时间（可选）
- [ ] 可设置报名是否需要审核
- [ ] 保存后配置生效

---

### 故事3：学员查看文案并报名
**作为** 学员  
**我希望** 查看已发布的文案并报名  
**以便** 参加培训课程

#### 验收标准
- [ ] 通过外链或二维码访问文案详情页
- [ ] 文案底部显示"立即报名"按钮（仅当开启报名且状态为已发布）
- [ ] 点击按钮跳转到报名表单
- [ ] 报名表单包含：姓名（必填）、单位（选填）、手机号码（必填）、报名班次（下拉选择，必填）
- [ ] 表单自动关联文案ID
- [ ] 提交后显示成功提示
- [ ] 若已报名，提示"您已报名，无需重复报名"

---

### 故事4：创建者查看报名名单
**作为** 创建者  
**我希望** 查看某文案的报名名单  
**以便** 管理学员信息

#### 验收标准
- [ ] 在操作列增加"名单"按钮
- [ ] 点击打开名单管理弹窗/抽屉
- [ ] 显示报名列表：序号、姓名、单位、手机号、报名班次、报名时间、状态
- [ ] 支持搜索（按姓名/手机号）
- [ ] 支持按班次筛选
- [ ] 支持导出Excel
- [ ] 显示统计信息：总报名人数、各班次人数

---

### 故事5：创建者管理报名信息
**作为** 创建者  
**我希望** 对报名信息进行增删改查  
**以便** 维护准确的学员名单

#### 验收标准
- [ ] **新增**：可手动添加报名信息
- [ ] **查看**：点击可查看报名详情
- [ ] **编辑**：可修改报名信息（姓名、单位、手机号、班次）
- [ ] **删除**：可删除报名记录（需确认）
- [ ] **审核**：若开启审核，可审核通过/拒绝报名
- [ ] 操作后列表实时更新

---

### 故事6：文案状态控制访问权限
**作为** 系统  
**我希望** 根据文案状态控制访问权限  
**以便** 确保报名流程正常进行

#### 验收标准
| 状态 | 创建者查看 | 公开访问 | 报名按钮 | 提示信息 |
|------|-----------|---------|---------|---------|
| 草稿 | ✓ | ✗ | 隐藏 | "内容暂未发布" |
| 已发布 | ✓ | ✓ | 显示 | - |
| 已归档 | ✓ | ✓ | 隐藏 | "项目已结束报名" |

## 数据模型设计

### 1. 文案表 (promotions) 扩展字段
```
enable_signup: boolean          // 是否开启报名
signup_config: {                // 报名配置
  require_approval: boolean,    // 是否需要审核
  max_signups: number,          // 总名额限制（可选）
  deadline: datetime,           // 报名截止时间（可选）
  classes: [                    // 班级班次列表
    {
      id: string,
      name: string,             // 班次名称
      max_count: number,        // 名额限制
      current_count: number     // 当前报名人数
    }
  ]
}
```

### 2. 报名表 (promotion_signups) 字段
```
id: number                      // 报名ID
promotion_id: number            // 关联文案ID
name: string                    // 姓名
unit: string                    // 单位
phone: string                   // 手机号
class_id: string                // 报名班次ID
class_name: string              // 报名班次名称（冗余）
status: enum                    // 状态：pending/approved/rejected
source: enum                    // 来源：online/manual
created_at: datetime            // 报名时间
updated_at: datetime            // 更新时间
```

## API接口规划

### 1. 预览相关
- `GET /api/promotions/:id/preview` - 获取预览数据（包含二维码、链接）

### 2. 报名配置
- `PUT /api/promotions/:id/signup-config` - 更新报名配置

### 3. 报名相关
- `GET /api/promotions/:id/signups` - 获取报名列表
- `POST /api/promotions/:id/signups` - 提交报名（学员）
- `POST /api/promotions/:id/signups/manual` - 手动添加报名（创建者）
- `PUT /api/promotions/:id/signups/:signupId` - 修改报名信息
- `DELETE /api/promotions/:id/signups/:signupId` - 删除报名
- `PATCH /api/promotions/:id/signups/:signupId/status` - 审核报名
- `GET /api/promotions/:id/signups/export` - 导出报名Excel

### 4. 公开访问
- `GET /api/promotions/:id/public` - 公开获取文案详情（用于外链）

## 技术实现要点

1. **二维码生成** - 使用 `qrcode` 库生成文案外链二维码
2. **Excel导出** - 使用 `xlsx` 库导出报名名单
3. **手机号验证** - 前端后端都进行手机号格式验证
4. **防重复报名** - 同一手机号对同一文案只能报名一次
5. **名额控制** - 报名前检查班次名额，超限时提示"该班次已满"
6. **截止时间** - 超过报名截止时间后自动隐藏报名按钮
